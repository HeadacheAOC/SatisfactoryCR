Utiliser ce module necessite des connaissances en PHP POO.

| Soft | Edition | Local |

## Commande de clonage
```Git Bash
git clone https://github.com/HeadacheAOC/SatisfactoryCR.git /c/dev/HeadacheAOC.SatisfactoryCR.git2
```

## settings.ini

Conformez le contenu du fichier setting.ini a votre environnement et preferences.

```ini
[SatisfactoryApp]
directory="C:\Program Files (x86)\Steam\steamapps\common\Satisfactory"
language_default="en-US"

[WebServer]
```
